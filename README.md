Restobot

Рестобот - система сбора и обработки сообщений из месседжера телеграмм в удобный дашборд. Рестобот - это удобный иструмент для мониторинга за торговым или ресторанным бизнесом.
Он удобен тем, что пользователь для отслеживаня будет пользоваться понятными для себя приложениями(Telegram, Google sheet и другие).

Как установить и пользоваться проектом:
Создаем .env по шаблону:

TELEGRAM_TOKEN= Заходим в BotFather(@BotFather) в телеграмме, создаем бота, сохраняем telegram token.
GOOGLE_SHEET_ID= Создаем таблицу в google sheet и находим google sheet id.
AI_API_KEY= Находим провайдера нейросетей (openrouter, proxyApi или другой) создаем апи ключ и сохраняем.
AI_MODEL= выбираем подходяющую ии модель для проекта
AI_BASE_URL=эту инфу нужно найти в документации у своего провайдера 
REDIS_URL=redis://redis:6379/0 - стандартная ссылка на redis. 
DEPLOY_HOST=айпи сервера, на котором лежать проект будет

Находим айдишники рабочих групп (к примеру с помощью бота @Getmyid_bot) и админов и тоже их сохраняем:
ADMIN_ID=
ALLOWED_USERS=
ALLOWED_GROUPS=

DEV_GROUP_ID=-
GROUP_KISA=-
GROUP_ASIENDA=-
GROUP_SINICHKA=
GROUP_BUFET=-
GLAVADMIN_ID=
